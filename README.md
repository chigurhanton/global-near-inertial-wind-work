# Intensifying global near-inertial wind work

This GitHub repository contains the source code, pretrained model, compact plotting-data caches, and figure-reproduction scripts associated with the manuscript **"Intensifying global near-inertial wind work."**

The study combines a damped-slab dynamical model with a physics-informed deep-learning correction constrained by Global Drifter Program observations. The framework corrects systematic amplitude biases in reconstructed near-inertial currents while retaining the slab-model phase evolution, and is used to diagnose multidecadal changes in global near-inertial wind work over 1979–2025.

## Physics-informed deep-learning framework

The main model is **AmpGainResNet**, a physics-informed amplitude-correction framework built around a damped-slab baseline.

The framework uses two inputs:

- an **8-channel environmental condition tensor** containing wind-stress components, wind-stress time derivatives, mixed-layer depth, longitude, latitude, and local Coriolis frequency;
- a **2-channel slab-model velocity tensor** containing the slab-model zonal and meridional currents.

The environmental features pass through convolutional stem layers and a **dilated temporal convolutional network (TCN)**. Two output heads estimate a bounded multiplicative gain and a non-negative residual amplitude correction. The corrected speed is constructed from these terms, while the slab-model velocity direction is retained when synthesizing the corrected vector velocity.

Training uses drifter-derived near-inertial currents and a physics-guided objective combining amplitude matching, logarithmic-scale matching, event-envelope consistency, temporal regularization, and gain/residual constraints. Dynamic masking reduces the influence of weak-wind/strong-current regimes that are more likely to contain substantial non-local near-inertial energy.

The model schematic is generated by `FigureS9.py` (see "Reproducing the figures" below).

## Installation

Python 3.10 or later is recommended. Create an isolated environment and install the packages listed in `requirements.txt`.

```bash
python -m venv .venv
```

On Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

For GPU-enabled training or inference, install the PyTorch build appropriate for the local CUDA configuration before running the model scripts.

## Reproducing the figures

Run the figure scripts from the **archive root**, because the scripts treat the current working directory as the project root.

Main figures:

```bash
python Figure1.py
python Figure2.py
python Figure3.py
python Figure4.py
```

Supplementary figures:

```bash
python FigureS1.py
python FigureS2.py
python FigureS3.py
python FigureS4.py
python FigureS5.py
python FigureS6.py
python FigureS7.py
python FigureS8.py
python FigureS9.py
python FigureS10.py
python FigureS12.py
```

Generated figures are written to `plots/`.

## Model training and inference

The main model-related files are:

- `model.py` — AmpGainResNet architecture;
- `losses.py` — physics-guided loss functions and regularization terms;
- `dataset.py` — dataset handling and conditioning variables;
- `config.py` — model/training configuration;
- `train.py` — training workflow;
- `diagnostics.py` — diagnostic utilities;
- `utils.py` — shared helper functions;
- `predict/predict.py` — inference workflow;
- `outputs/best_amp_gain_model.pt` — pretrained checkpoint used for the reported correction diagnostics.

## Source data

The large source datasets are **not redistributed in this archive**. They can be obtained from the original providers:

- **Global Drifter Program (GDP) hourly product:** https://www.aoml.noaa.gov/phod/gdp/hourly_data.php
- **ERA5 reanalysis:** https://doi.org/10.24381/cds.adbb2d47
- **ORAS5 ocean reanalysis / mixed-layer depth:** https://doi.org/10.24381/cds.67e8eeb7
- **NOAA monthly Niño 3.4 SST index:** https://psl.noaa.gov/data/timeseries/month/Nino34/

The scripts under `data/` document major preprocessing and damped-slab calculation steps. Users interested only in reproducing the published figures should use the supplied files in `cache/` whenever possible.
